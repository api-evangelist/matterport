# Matterport

> Matterport (a CoStar Group company) is a spatial data platform that captures physical spaces and turns them into dimensionally-accurate 3D digital twins. Developers build on a GraphQL API family (Model, Account, Import), the Property Intelligence API, the Custom Roles API, and a set of JavaScript SDKs that embed and script the 3D Showcase player.

## APIs
- [Developer Portal](https://matterport.com/developers): Matterport APIs and SDKs overview.
- [GraphQL API Reference](https://api.matterport.com/docs/reference): Model, Account, and Import API reference and interactive console.
- [GraphQL endpoint](https://api.matterport.com/api/models/graph): HTTP Basic auth with an API Token (Token ID + Token Secret).
